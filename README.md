# Tagging Studio

Open `index.html` in a modern browser, or upload the files to a GitHub repository and enable GitHub Pages.

Features:
- Responsive dark midnight/periwinkle interface
- English POS tagging with approximate C5/C7-style profiles
- Manual token tag correction
- Corpus analytics and word-frequency search
- TXT and DOCX input
- Copy and TXT export

Note: This is an independent educational heuristic tagger, not the Lancaster CLAWS engine or certified CLAWS output.
